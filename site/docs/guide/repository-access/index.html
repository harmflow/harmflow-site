Granting access to repositories

A GitHub task works the GitHub repositories it lists. For each one, it names the clone on your Mac and the branch its work starts from, main unless it names another.

The task's harness works those repositories with Git and the GitHub CLI, gh, signed in on your Mac, so a task reaches what that sign-in reaches. The built-in issue implementer, which a new GitHub task selects by default, opens draft pull requests and never merges one.
