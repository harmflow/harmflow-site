Exporting and importing a task

A task can leave your Mac as a file and come back as a task, on the same machine or another one. Export a task to move it to another machine, to share it, or to keep a copy. This page says what the exported file holds, what it leaves out, and what you see when you import it.

Exporting a task

In the Tasks screen, each task's row has an Export button. HarmFlow asks where to save the file, with a name taken from the task's identifier, such as weekly-report.yaml, and shows Task exported. once it is saved.

What the file holds

The exported file is the task's own file, as you or HarmFlow wrote it: its comments and the order of its keys are kept. It holds what the task is — its type, its work, its schedule, its AI tools, and its permissions — and nothing else.

What the file leaves out

The file carries no record of any run, even for a task that has already run many times. Nothing a run left behind is in it:

  • no execution record;
  • no session;
  • no pull request link;
  • no log;
  • no folder path;
  • no revision;
  • no next firing.

Your own agents and skills stay on your machine, too: the file names the ones the task cites, but does not carry them.

Secrets

If a password or a token was typed into a task's prompt, its description, or a comment of its file, the export masks it: the secret does not reach the exported file.

That is a safety net, not a place to keep secrets: do not type secrets into a task, and read an exported file before you share it.

Importing a task

In the Tasks screen, choose Import. In the Import a task window, choose a .yaml file with Choose file… or paste its content, then choose Import.

  • The file is checked like any other edit. A file that is not a valid task is not imported, and HarmFlow names what is wrong with it.
  • A task with the same identifier. To replace a task you already have with the imported one, tick Replace a task with the same identifier first.
  • A script task. A script task runs a program with your rights, so HarmFlow first shows what it runs, where, and when. Choose Import disabled to import it: it is saved disabled, so check its program, then enable it.
  • A missing agent or skill. When the task cites an agent or a skill this machine does not have, the import still succeeds, and HarmFlow shows a warning that names it.

After an import

HarmFlow shows Task imported., the task appears in the task list, and it opens in the task editor. From there it is a task like any other: edit it, save it, and run it.
