The general system prompt

The general system prompt is a set of instructions you write once, in Settings, and that every session of a GitHub task or a general task receives. Use it for what you want every session to know, whatever the task: how you like commit messages written, say, or a convention your repositories share.

Where the field is

The field is in Settings, in the AI tools section, in its General system prompt panel, under the quota shares. It is labeled Instructions for every session. The Settings screen says what the rest of that section holds.

  • It is empty by default. While it is empty, sessions receive nothing from it.
  • It takes at most 20,000 characters. A longer text is refused: the field shows the error, and the text saved before stays as it was.

A draft until you save it

What you type in the field is a draft until you press Save. Until then, no session receives it. If you leave the section with a draft not saved, the app asks first whether to discard it.

To stop sending instructions, empty the field and save.

Which sessions receive it

  • Every session of a GitHub task or a general task receives the text, on Claude Code and on Codex alike.
  • A session that starts after a failover receives it too, as the session before it did. What else the next harness is given is on Failover when a quota runs out.
  • A change reaches the next attempt with no restart of the daemon or the app. HarmFlow reads the saved text each time it starts an attempt, so an attempt already running keeps the text it started with, and the next one gets the new text.
  • A script task never receives it. A script task runs your command and no harness, so there is no session to give it to.

Where the text goes

The text comes first, under its own heading, as your general instructions. HarmFlow's own instructions for the session follow it, whole, under a heading of their own: where the task's parameters and history are, and where to leave its progress and its report. Your text adds to them; it cannot remove or replace them.

The task's own prompt is still the task: the general system prompt goes beside it, never in its place.

One text for every task

The text is the same for every task. There is no option to leave a task out of it, and no field for a prompt of this kind per task: what one task alone needs goes in that task's prompt.

The text belongs to Settings, not to a task, so an exported task does not carry it. Exporting and importing a task says what the file holds.
