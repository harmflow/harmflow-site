The interface's languages

The HarmFlow app's interface comes in a fixed set of languages. Once the app is installed, you can choose the one it shows.

The three languages

The interface is available in three languages:

  • Portuguese (Brazil)
  • English (United States)
  • Spanish (Spain)

Choosing the language

The language is chosen in Settings. Open the General section, in the Interface group of the section list: its Language panel holds one list of languages, and nothing else. Each language in the list is written in its own name, beside a System language choice.

No other language can be added

The translations are part of the app, and HarmFlow keeps them up to date. They come with the app, not from a file you add. So there is no button, file field, or link to add, import, or download a language: the three above are the ones the app offers.
