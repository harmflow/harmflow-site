What a task notifies about

HarmFlow tells you what your tasks do with a notice. Each task chooses the events it notifies about, and has a switch of its own that turns its notices off. One level in Settings then quiets the notices of every task at once.

Where a task's notices are set

Open the task in the task editor and go to its Notifications section. It holds two things:

  • Native notifications: the task's own switch. While it is off, the task raises no notice, whatever events it chose. It starts on.
  • Notify me about: one checkbox for each event the task can notify about. Only the events you check raise a notice.

The choice belongs to the task, so two tasks can notify about different events. An execution that is already running keeps the choice it started with; an edit applies from the task's next execution.

The events a task can choose

  • Execution started: an execution of the task starts.
  • Execution completed: an execution completes.
  • Operational failure: an execution fails. An execution that was interrupted, because the daemon stopped while it ran, counts as a failure too.
  • Cancellation: an execution is cancelled.
  • Needs attention: an execution needs a person to act.
  • Draft PR created: an execution opens a draft pull request.
  • Draft PR updated: an execution updates a draft pull request.
  • Tests failed: the tests an execution ran failed and need review.
  • AI tool unavailable: the task's AI tool is unavailable.
  • No alternative AI tool: the AI tool cannot go on, and no other AI tool the task names can take over.

A new task notifies about five of them: Execution completed, Operational failure, Needs attention, Draft PR created, and No alternative AI tool. Check or uncheck any of them to change it.

Quieting notices across tasks

When notices fire too often, you need not edit each task. Open Settings, then Notifications, and choose a Notification level, which applies to every task at once:

  • All: every task notifies about each event it chose.
  • Failures and attention only: only the events of a failure or of something you must act on go through — an operational failure, needs attention, tests failed, and either AI tool event.
  • None: no task raises a notice.

The level only filters the events each task chose; it never adds one. A change of level applies at once. The notification level explains it in detail.
