The notification level

HarmFlow tells you what your tasks do with a notice, and each task chooses the events it notifies about. The notification level quiets those notices without turning them off for good: it is one setting for every task, and it works on top of the events each task chose.

Where to set it

Open Settings, then Notifications, and choose a Notification level. The level applies to every task at once, so you change one setting rather than each task. It starts at All.

The three choices

  • All: every notice goes through. A task notifies about each of the events it chose.
  • Failures and attention only: only a failure, or something that needs you to act, goes through — an execution that failed, tests that failed, an execution that needs your attention, or a harness that is unavailable. A task that notifies on completion and on failure raises a notice when an execution fails, and none when one completes.
  • None: no task raises a notice.

It filters, it never adds

The level only filters the notices of the events each task chose. It never adds an event a task did not choose: with All, a task that notifies on failure only still raises no notice when an execution completes, and with Failures and attention only, a task that notifies on completion only raises none at all.
