The list of active executions

The Executions screen is the dashboard's first screen. It lists every execution that is active right now, all at once, one card each, so with several tasks running you can see each of them side by side. Its heading counts them: with three executions running, it reads "Active executions (3)". When nothing is running, the list says so and offers to take you to your tasks.

What a card shows

Each card belongs to one execution and shows only that execution's details:

  • Its task. The card's title is the task's name, followed by the issue the execution works on, when it works on one; the Task field gives the task's ID.
  • Its AI tool. The Run by field names the AI tool running it, Claude Code or Codex.
  • Its repository. The Repository field names the repository the execution works in.
  • Its elapsed time. The Start field gives the time the execution started and how long it has been running. The elapsed time counts up on the card, second by second, as the execution runs.
  • Its state, in a chip beside the title.

The states a card shows

An active execution is in one of these states:

  • Preparing: the execution is getting ready to work, such as preparing its workspace.
  • Running: the execution is at work.
  • Switching AI tool: the execution is moving to the next AI tool the task names.
  • Testing: the execution is running tests of its work.
  • Publishing: the execution is publishing its result, such as a pull request.

Each card shows the state of its own execution, so the cards can differ at the same time: one execution may be running while another is preparing and a third is switching to another AI tool.

Cancelling one execution

Each card has its own Cancel button. Choosing it asks you to confirm, then stops that execution and no other: the execution's AI tool is asked to stop, and after a grace period its processes are ended. Its logs and its worktree are kept, and every other execution on the screen goes on running. While the execution stops, its button reads "Cancelling…".
