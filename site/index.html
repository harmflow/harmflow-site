Coming to the Mac App Store

Automations that run on the agents you already use.

For developers on the Mac: HarmFlow runs Claude Code and Codex on a schedule, and follows every execution as it happens.

Follow HarmFlow on GitHub

Prefer to build it yourself? The community edition builds from the source.

One file, one schedule.

Every task is one YAML file: its prompt, its harness, and when it runs, on a cron or an interval. A run the Mac slept through runs when it wakes. 

schedule:
  cron: "0 2 * * 1-5"   # weeknights at 02:00
  missedRun:
    policy: run_on_resume  # asleep? run on wake

Every execution, live.

The harness reports its progress as it works. The desktop app shows each event as it arrives, and the report the session leaves when it ends.

  1. 02:00:01 Started on claude-code
  2. 02:00:03 Workspace ready
  3. 02:04:18 Progress: tests pass
  4. 02:07:40 Report written

Quota out? It keeps going.

When a harness's quota runs out, or the harness is unavailable, the task moves to the next harness you named, and HarmFlow tells you.

claude-codequota exhausted → codexrunning

Your harness does the work.

HarmFlow runs it on time, watches it, and tells you how it went. Follow it on its way to the Mac App Store.
